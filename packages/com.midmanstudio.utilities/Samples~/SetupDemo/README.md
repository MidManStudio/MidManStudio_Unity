# MidMan Studio Utilities — Setup Demo

A starting point for wiring up the persistent "Managers" hierarchy and the
per-system demo scenes described in `Documentation~/scenesetup.md`.

## Contents

- `Scenes/SetupDemoScene.unity` — empty base scene. Use it (or a duplicate per
  system) to follow the walkthroughs in `Documentation~/scenesetup.md`:
  Tick Dispatcher + Tick Delay Bench, UI State System, Library System,
  Pool System, Audio System, and SceneDependencyInjector.
- `Prefabs/` — drop your assembled "Managers" prefab here once built.
